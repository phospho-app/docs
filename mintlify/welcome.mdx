Phospho is how ML engineers make real robots intelligent. 
We provide the hardware, libraries, and remote control capabilities so developers can collect data, 
train AI models and deploy applications to real robots in minutes instead of months.

# Highlights

- 🕹️ Teleoperate robots to capture datasets in minutes
- ⚡ Train AI models such as ACT or π0 with one command
- 🦾 Compatible with the SO-100 arm 
- 🚪 Dev-friendly API
- 🤗 Fully compatible with LeRobot and HuggingFace
- 🖥️ Runs on macOS, Linux and Windows
- 🥽 Meta Quest app for teleoperation
- 📸 Supports most cameras (classic, depth, stereo)
- 🔌 Extend it with your own robots and cameras

# Installation

In a terminal, run the following command:

```bash macOS and Linux
curl -fsSL https://raw.githubusercontent.com/phospho-app/phosphobot/main/install.sh | bash
```
Then, fire up the the server:

```bash 
phosphobot run
```

On macOS, it can take up to 15 seconds for the server to start for the first time because of macOS security settings.

# Updates

We're shipping updates to improve your experience, add new features, and fix issues on a daily basis.
Keep your installation up-to-date to benefit from the latest improvements.

On Mac:

```bash
brew update && brew upgrade phosphobot
```

On Linux:

```bash
sudo apt update && sudo apt install --only-upgrade phosphobot
```

If you use the control module of the dev kit, simply restart it, updates will be installed automatically.
