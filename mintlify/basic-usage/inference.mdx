So you just trained an AI model and now you want to use it to control your robot. 

# Setup an inference server

First, you need to setup an inference server. This servers runs on a beefy machine that can run the AI model. It can be your own machine, a cloud server, or a dedicated server. 

<Note>If you chose a remote location, chose the closest location to minimize latency.</Note>

To setup the inference server, follow the instructions in the link below:

# Update the inference Settings

If you haven't already, start the phosphobot server.

```bash
phosphobot run
```

In your browser, in the phospshobot dashboard, go to the Admin Settings. 

Update the _Inference Settings_ with the URL (or IP adress) and port of your inference server. This is the address where the phosphobot server sends the images to get the next action to take.

# Start automatic control 

<Warning> Make sure the robot is in a safe position before starting the automatic control. </Warning>

Use the [/auto/start](/control/auto) endpoint to start the automatic control. 

The phospshobot server calls the inference server to get the next action to take.

# Stop automatic control

Use the [/auto/stop](/control/stop-auto) endpoint to stop the automatic control.
