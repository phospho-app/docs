You just [recorded a dataset](/basic-usage/dataset-recording) and now you want to train an AI model to control your robot. 
Here's how you can do it.

<Note>Don't have a dataset? Use one of ours: `PLB/simple-lego-pickup-mono-2`</Note>

You dataset is saved in the **LeRobot** format and uploaded to your Hugging Face account. 
Any training script compatible with this dataset format can be used to train your AI model.

You can train an AI model (VLA) directly from your phosphobot dashboard. 
Training will be run on the phospho cloud, so you don't need to worry about the GPUs.

Alternatively, you can train your model using the following scripts on your own machine:
- [ACT](/basic-usage/training#act-action-chunking-transformer) (Action Chunking Transformer) trained using LeRobot training scripts
- [pi0](/basic-usage/training#pi0-pi-zero) trained using openpi by Physical intelligence

## Training on the phospho cloud

Training will be run on the phospho cloud, so you don't need to worry about the GPUs. 
You will need to create a phospho account and login.

If you haven't already, launch the phosphobot server:

```bash
phosphobot run
```

and go to the dashboard in your browser at [http://localhost](http://localhost).

In the **AI Training and Control** section, input the the name of your dataset (example: `PLB/simple-lego-pickup-mono-2`) and hit the **Train AI Model** button. 
And boom, your model will start training.

Training can take up to 3 hours. You can view the training and trained models in the **View Trained Models** tab.

Your model will be upled to the phospho secondary HuggingFace page: [phospho-app](https://huggingface.co/phospho-app) and named something like `phospho-app/YOUR_DATASET_NAME-A_RANDOM_ID`.

## Training on your own machine

### ACT (Action Chunking Transformer)

<Warning>
You need a GPU with at least 16GB of memory to train the model.
</Warning>

On the device where you want to run the training, install the [Phosphobot package](https://github.com/phospho-app/phosphobot):  

   ```bash
   pip install --upgrade phosphobot
   ```

2. Clone the [LeRobot repository](https://github.com/huggingface/lerobot) and install it:  

   ```bash
   git clone https://github.com/huggingface/lerobot.git
   cd lerobot
   pip install -e .  # Requires Python 3.10+
   ```

3. *(Optional)* If you want to use **Weights & Biases** for tracking training metrics, log in with:  

   ```bash
   wandb login
   ```

4. Run the training script with the following command in the `lerobot` repository (Set --device=mps for Apple Silicon (Mac M1/M2), `cuda` if you have an NVIDIA GPU or `cpu` if you don’t have a GPU). Ensure that your `lerobot` virtual environment is activated.  

   ```bash
   sudo python lerobot/scripts/train.py \
     --dataset.repo_id=<HF_USERNAME>/<DATASET_NAME> \
     --policy.type=<act or diffusion or tdmpc or vqbet> \
     --output_dir=outputs/train/phoshobot_test \
     --job_name=phosphobot_test \
     --device=mps \ # mps or cuda 
     --wandb.enable=true
   ```

5. Your trained model is saved in `lerobot/outputs/train/`.  

#### Running on replicate

To make it easier to train your model, we provide a training script that you can run on the **Replicate** platform, a cloud service that provides GPU instances and scripts to train your AI models and run inference.

Check out our pipeline here: [Replicate ACT pipeline](https://replicate.com/phospho-app/act-policy)

You'll need to provide a Hugging Face dataset ID and token on which to train the policy.

## Pi0 (Pi-Zero)

We added support for the SO-100 arm in this fork of the openpi repository. 
For a full fine-tuning of the model, you will need at least 70GB of GPU memory (we recommend using a A100 (80GB) / H100).

```bash
git clone https://github.com/phospho-app/openpi.git
cd openpi
```
Install UV if you don't have it already:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source $HOME/.local/bin/env
```

Setup the environment using uv:

```bash
GIT_LFS_SKIP_SMUDGE=1 uv sync
```

*(Optional)* If you want to use **Weights & Biases** for tracking training metrics, log in with:  

```bash
# Get your auth token at https://wandb.ai/authorize
uv run wandb login
```

By default, our training config uses the `PLB/Orange-brick-in-black-box` SO-100 dataset.
Make sure you dataset has a correct task description for each task in the dataset (in our dataset, it's _"Put the orange brick in the black pot"_).
Edit the config file `src/openpi/training/config.py` to change the dataset to your own.

Then, you can train your model using the following command:

```bash
uv run scripts/compute_norm_stats.py --config-name pi0_so100
# Main train command in nohup, it will take a while
XLA_PYTHON_CLIENT_MEM_FRACTION=0.9 uv run scripts/train.py pi0_so100 --exp-name=pi0_so100_blackbox --overwrite
```

Once training is done, push your model to Hugging Face:

```bash
huggingface-cli login  # Follow the authentication steps
huggingface-cli repo create your-model-name --type model

# Push direclty using the cli
huggingface-cli upload USERNAME/your-model-name \
  ~/path/to/folder/ \
  --repo-type model
```
